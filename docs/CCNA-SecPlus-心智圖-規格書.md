# CCNA × Security+ 知識地圖 — 規格書

版本：對應心智圖輸出 `lesson1-v4`　｜　最後更新：本次對話彙整

## 1. 專案目的

一份可互動導覽的知識地圖，用 Cytoscape.js 整合 CCNA（網路工程）與 Security+（資訊安全）兩張證照的知識體系，資料庫用 Airtable，目的是搭配教材（目前為 CompTIA Security+ SY0-701 簡報）邊複習邊檢視知識結構。後續會再納入 Coursera Google Cybersecurity 課程內容，但目前優先完成 Security+ 部分。

## 2. 資料庫（Airtable）

Base 名稱：CCNA×Security+ 知識地圖　｜　單一資料表：`Nodes`

### 2.1 欄位總覽

| 欄位 | 型別 | 用途 | 目前狀態 |
|---|---|---|---|
| Label | 單行文字 | 節點顯示名稱，格式見 3.1 | 已依規則統一 |
| Node Key | 單行文字 | 跨表穩定識別碼（如 `l1-confidentiality`），匯出 JSON 用此當 key | 已建立 |
| Content | 多行文字 | 節點內文說明 | 已建立 |
| Table Diagram Data | 多行文字 | 比較表格（markdown 語法）或流程圖描述文字 | 已建立 |
| Flow Order | 數字 | 若節點是某個流程圖裡的一個步驟，填入順序（1,2,3…） | 已建立 |
| Hyperlink | URL | 外部參考連結 | 已建立，多數留空 |
| Source Slide | 單行文字 | 來源簡報與頁碼 | 已建立 |
| Category | 單選（Root/CCNA/SecPlus/Overlap） | 領域分類 | 欄位存在，值留白（使用者要親自分類） |
| Color Override | 單行文字 | 節點顏色，格式為 `顏色名稱 (色碼)`，例如 `blue (#2196F3)` | 使用者已手動填入部分節點 |
| Shape（英文，舊） | 單選，7 個選項 | 節點形狀（Cytoscape 形狀關鍵字） | 保留但不再更新；因工具限制無法將既有選項改名 |
| **形狀 Shape**（中文，新） | 單選，25 個選項 | 節點形狀，選項為中文名稱，涵蓋 Cytoscape.js 全部內建形狀 | 已建立並取代舊欄位 |
| Size | 數字 | 節點大小 | 已依階層深度填入預設值（root 最大、葉節點最小） |
| Status | 單選（待讀/複習中/已讀） | 個人讀書進度 | 欄位存在，尚未使用 |
| Parent | Linked Record（自我關聯） | 階層歸屬（一個節點僅一個 parent） | 已依簡報章節結構建立 |
| Related | Linked Record（自我關聯） | 跨段落／跨主題關聯（一個節點可多個） | 已依實際重複出現的概念建立 |
| Pos X / Pos Y | 數字 | 心智圖畫布座標 | 依使用者手排版面的分支順序，用工整對稱演算法算出，並對少數刻意分組的節點做手動微調 |

### 2.2 為什麼選 Airtable 而不是 Google Sheets

Google Sheets 沒有欄位型別與關聯驗證，且 Claude 只能讀不能寫。Airtable 有 Linked Record（關聯驗證）、Single Select（下拉選單），且有官方 MCP 連接器，讓 Claude 可以直接讀寫，不需要每次手動貼資料。

### 2.3 已知工具限制

Claude 目前使用的 Airtable 工具**沒有辦法**：
- 直接編輯既有 Single Select 欄位的選項名稱（只能在新建欄位時設定選項）
- 直接編輯 Google Docs／Google Sheets 內容（只能讀取）
- 刪除單一欄位（只能刪除整張表）

所以像「把 Shape 選項翻成中文」這種需求，是用「新建一個欄位取代舊欄位」的方式繞過去的。

## 3. 視覺呈現規則

### 3.1 節點名稱（Label）格式

統一順序：**英文 → 中文 →（括號補充）**，每段用換行分隔。例如：

```
Confidentiality
機密性
```

```
IAAA
存取控制的核心
（身分與存取管理 IAM）
```

### 3.2 節點大小

依階層深度分五級：root 最大（100），每往下一層遞減（75/58/44/34）。使用者可日後依複習狀況個別覆蓋。

### 3.3 顏色與形狀

目前由使用者依照教材內容手動指定（一邊複習一邊決定），欄位格式：
- 顏色：`顏色名稱 (色碼)`，例如 `blue (#2196F3)`
- 形狀：中文選單，對應 Cytoscape.js 內建形狀（詳見附錄 A）

### 3.4 兩種邊（Edge）

| 類型 | 樣式 | 意義 |
|---|---|---|
| Hierarchy（階層邊） | 實線、亮綠色、較粗，帶箭頭 | 父子關係，對應 Parent 欄位 |
| Related（跨段落關聯） | **不在畫布上畫出**，只在側邊欄以按鈕呈現 | 同一概念在不同段落重複出現時的連結，對應 Related 欄位 |

> 決策紀錄：曾考慮用 Cytoscape compound node 做「紅藍底色大框」分組，但因為 `Overlap` 分類的節點需要同時跨兩個領域，與 compound node 嚴格樹狀的限制衝突，故不採用（ADR-0001）。

### 3.5 版面座標

座標不是單純的自動置中演算法，而是照使用者手排的心智圖截圖，保留其分支左右順序後，用工整對稱的方式重新計算；其中三組使用者刻意分組排列的節點群（見下方）以手動座標覆寫：

- 「不可否認性 vs 可問責性（比較）」：獨立置於更深一層，水平位置置中於它所連結的兩個節點之間
- 「安全控制分類」下的四個控制類型：2×2 緊湊分組，而非單排
- 「指令性控制／嚇阻性控制／補償性控制」：獨立成一排，位於「預防／偵測／校正」那排的下方並往右錯開

## 4. 心智圖檢視器（HTML/Cytoscape.js）功能

### 4.1 基本瀏覽
- 星形／色塊節點，依 Airtable 資料渲染顏色、形狀、大小、位置（preset layout，非自動排版）
- 點節點開啟右側側邊欄：顯示來源頁碼、內文、比較表格（若有）
- 側邊欄依序顯示：上層節點（Parent）→ 下層節點（Children）→ 跨段落關聯（Related），皆為可點擊跳轉按鈕
- 左上角搜尋框：輸入關鍵字，不符合的節點會淡化
- WASD 平移畫面；滑鼠滾輪縮放

### 4.2 版面規則
- 沒有選取節點時，側邊欄完全隱藏，不佔版面
- 側邊欄寬度依內容需求自動調整，上限為畫面寬度的 40%，超過則表格內部橫向捲動（表格文字不斷行）
- 節點多行文字的行高、外框寬度已調整避免互相重疊

### 4.3 編輯模式（v4 新增）

| 操作 | 說明 |
|---|---|
| 🔒／🔓 鎖頭圖示（左上角） | 切換編輯模式開關，開啟時畫布外框會亮起提示 |
| 點節點（編輯模式下） | 側邊欄切換成編輯表單，可修改：名稱、內文（多行文字框）、形狀（下拉選單，中文）、顏色（調色盤）、大小（數字輸入） |
| 表格內容 | 不可編輯（維持原樣） |
| Ctrl+Z / Cmd+Z | 復原上一步編輯（僅在編輯模式開啟時作用） |
| ⬇ 匯出按鈕 | 產生本次所有異動的 JSON 檔案並下載，命名規則：`mindmap_{版號}_{時間戳記}.json`，例如 `mindmap_lesson1-v4_20260730-153000.json` |

**匯出 JSON 格式：**
```json
{
  "version": "lesson1-v4",
  "exported_at": "2026-07-30T07:30:00.000Z",
  "changes": {
    "l1-confidentiality": { "color": "#1E88E5", "size": 50 },
    "l1-dad": { "label": "新的名稱\n新的中文" }
  }
}
```
只包含**有異動**的節點與欄位，不會整份重新輸出。

### 4.4 目前的限制
- 編輯模式無法調整 Parent／Related 關聯（這類欄位需要對照 Airtable Record ID，瀏覽器端無法安全處理）
- 編輯模式無法調整節點座標（拖曳定位）
- 匯出的 JSON 需要使用者上傳給 Claude，由 Claude 讀取後手動呼叫 Airtable API 寫回，不是即時同步

## 5. 工作流程（目前階段）

1. 使用者上傳教材簡報（PDF）
2. Claude 依簡報的章節結構，抽取重點成節點，自動推斷 Parent 階層
3. Claude 找出同一概念在不同段落重複出現的情況，建立 Related 關聯
4. 圖表／流程圖／比較表：流程圖類用 `Flow Order` + 共同 Parent 呈現；比較表格用 markdown 表格語法存入 `Table Diagram Data`
5. Claude 把資料寫入 Airtable，視覺樣式欄位（Category/Color/Shape/Size）留白或給預設值
6. Claude 產出 Cytoscape.js HTML 供使用者複習與檢視
7. 使用者一邊複習一邊在 Airtable 或心智圖編輯模式調整樣式，用「⬇ 匯出」把異動交給 Claude 寫回 Airtable

## 6. 版本控制（未來規劃）
